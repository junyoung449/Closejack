## ✅ 확정된 것 (요약)
- 장르/구조: 싱글플레이어 로그라이크 덱빌딩(블랙잭 변형). **지원 언어 = 한국어·영어(현지화 대상).**
- **막 구성(2026-06-10 확정)**: **8막**, 한 막 = **전투 - 여정 n회 - 전투 - 여정 m회 - 보스 전투 - 여정 l회**. n/m/l = 직전 적 선택에서 결정. 보스 8회 전승 = 승리, 패배 = 플레이어 HP 0.
- **시작**: 시작 덱 선택 → 1막. **적 선택 = 2지선다**(한쪽 ~30% 강함 + 보상 多, 보상 = 여정 횟수 + 금화량 차이).
- 카드 3종: **플레잉 / 홀(일회성) / 에이스(영구 강화)**. 모든 카드 = 무게·가치 2축 + 중앙 그림 효과(없을 수도).
- 핸드: **레드(상)/블루(하)**, 각 5슬롯·무게 제한 21. 데미지 = (레드 가치합 × 블루 가치합) × 1.5^(황금 칩). 핸드별 버스트(넘긴 핸드만 3번째 슬롯 제외 붕괴, 턴 종료까지 미복구).
- **황금 칩**(구 황금 코인): 조건 명칭 확정(2026-06-11) — **redjack/bluejack**(무게 정확 일치)·**red guys/blue guys**(5슬롯 만석) 각 1개 + 콤보 **closejack**(redjack+bluejack)·**full guys**(양 핸드 만석) 각 추가 1개 = **기본 최대 6개**(구 4개). 에이스·그림 조건으로 추가 가능(상한 없음), 칩 1개당 ×1.5, **스탠드 시 리셋**.
- 턴/라운드 정의: **라운드** = 누군가 쓰러질 때까지(=전투), **턴** = 상호행동 단위(턴 집합=라운드).
- 플레이어 6대 동작: **레드 히트·블루 히트·스탠드·홀 카드·판 엎기·덱 보충** (+에이스 드래그 정렬). 히트/스탠드 효과 발동 순서 = 레드 좌→우 → 블루 좌→우 → 에이스 위→아래.
- 판 엎기: 라운드당 기본 1회, 턴 무효+적 계획 유지, 그 라운드 적 공격력 ×2.
- 여정 구조: 한 여정 단계 = **두 구체 여정 중 2지선다** → 고른 여정이 자기 선택지 제시(중첩 X). **온천·보물더미 외 스킵 가능.**
- 여정 종류(8): **에이스/플레잉/홀 카드 상인**(구매 1개) · 보물더미(금화, 스킵X) · 모닥불(카드 소각, 풍요로운→최대3장) · 온천(체력, 스킵X) · **에이스/플레잉/홀 카드 후원자**(무료, 수량 수식어 X) · **화가**(플레잉 7장→그림1개를 고른1장에, 풍요로운+희귀도 O·궁핍한 X) · 아르카나(타로 변형, 광기 빈번) · 동굴(무작위+체력손실).
- 여정 수식어: 수량(풍요로운 +2 / 궁핍한 −1), 희귀도(희귀한 / 찬란한 / 광기의=최고희귀+가림). 군별 1개씩 결합 가능.
- 리셔플은 그 턴 0장 뽑았을 때만, 턴 포기(적 행동) — 덱 압축 견제. 0장이면 다음 턴 자동 보충.
