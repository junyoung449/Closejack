## ✅ 확정된 것 (요약)
- 장르/구조: 싱글플레이어 로그라이크 덱빌딩(블랙잭 변형), **8막**(막 = 적선택→여정→적선택→여정→보스), 보스 8회 전승 = 승리, 패배 = 플레이어 HP 0.
- 카드 3종: **플레잉 카드 / 홀 카드(일회성 아이템) / 에이스(영구 강화, 발라트로 조커 대응)**. 모든 카드 = 무게·가치 2축 + 중앙 그림 효과.
- 핸드: 상단/하단, 각 5슬롯·무게 제한 21. 공격 = (상단 가치합 × 하단 가치합) × 1.5^(황금코인). 핸드별 버스트(넘긴 핸드만 중앙(3번째) 제외 붕괴).
- 황금 코인: 무게 정확히 21 / 5슬롯 가득 / 에이스·그림 조건 → ×1.5.
- 턴: 무작위 1장 드로우 → 상/하 핸드 선택 히트 → 스탠드(전용 버튼). 사용 카드 → 버린 덱. 리셔플은 그 턴 0장 뽑았을 때만, 턴 포기(적 행동) — 덱 압축 견제.

## ☐ 채워야 할 기획 (디테일 다량 필요 — 앞으로 할 일)

> 각 항목은 별도 세션에서 깊게 파고들어 `KO_설계도.md`에 기록한다.

- [ ] **1. 시작 덱** — 최초 해금 덱, 덱 종류, 덱별 차이(구성/보유 홀 카드/카드 슬롯 수)
- [ ] **2. 플레잉 카드 풀** — 무게/가치 분포, 중앙 그림(효과)의 종류·예시
- [ ] **3. 에이스(강화) 풀** — 효과 예시(코인 추가, 배수, 무게 조정, 조건부 등), 슬롯 수
- [ ] **4. 홀 카드 풀** — 일회성 아이템 효과 예시, 슬롯 수
- [ ] **5. 적 / 보스** — 적 공격 패턴, 공격 예고 방식, 8막 보스 구상, 난이도 ↔ 여정 수 매핑
- [ ] **6. 여정 최종 구성** — 상인(플레잉/홀/에이스), 화가, 체력·금화 이벤트, 카드 교환, 희생-이득 등 확정 + 등장 규칙
- [ ] **7. 경제** — 금화 획득/소비 경로, 상점 가격, 코인 배수 강화 비용
- [ ] **8. 수치/밸런스** — 플레이어 HP, 적 HP·데미지 기준, 무게/가치 스케일
- [ ] **9. 메타 진행** — 덱·카드·적 해금 조건, 도전과제
