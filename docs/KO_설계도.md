## 2. 핵심 변형 규칙 (Closejack 고유 메카닉)

### 2-1. 카드
모든 카드는 2가지 숫자 요소 **무게(weight)** 와 **가치(value)** 를 가지며, 중앙의 그림으로 다양한 효과를 가질 수 있다.

> **설계 의도(무게·가치 분리)**: 두 숫자를 분리해 다양한 카드 풀을 만든다. 예) 강화로 무게 3·가치 20인 카드, 무게를 늘리는 대신 효과를 주는 카드, 핸드 전체의 무게를 줄이는 대신 자기 가치를 희생하는 카드 등.

카드 종류는 3가지:

| 종류 | 역할 | 배치 |
|------|------|------|
| **플레잉 카드 (Playing Card)** | 핸드를 구성하는 기본 카드 | 덱 → 핸드 |
| **홀 카드 (Hole Card)** | (구 '트릭 카드') 일회성 아이템. 보드에 영향을 미친다. | 우하단 홀 카드 슬롯 |
| **에이스 (Ace)** | 영구 강화 카드(발라트로의 '조커' 대응). 플레잉을 강화. 상점·여정으로 획득. | 좌측 |

> 강화 카드 명칭은 **'에이스(Ace)' 로 확정**. ('ace'가 들어가는 다양한 단어로 언어유희(말장난) 활용 의도)

### 2-2. 덱 · 시작 선택 · 버린 카드 · 보충(리셔플)
- 게임을 시작하면 플레이어는 **시작 덱**을 선택한다. 덱은 플레이 여하에 따라 **해금**되며, 덱마다 **구성 / 보유 홀 카드 / 카드 슬롯 수** 등의 차이를 갖는다.
- **버린 카드 덱(discard)**: 플레이어는 핸드에 카드를 주고 스탠드로 턴을 종료한다. 그렇게 사용된(핸드에 들어간) 카드는 **버린 카드 덱**으로 간다.
- **덱 소진**: 덱의 카드가 점점 부족해져 **한 장도 뽑지 못하게 되면**, 플레이어는 현재 상태로 **스탠드할 수밖에 없다**.
- **덱 보충(리셔플)**:
  - 플레이어가 **그 턴에 덱에서 카드를 한 장도 꺼내지 않은 경우**에 한해, **버린 카드 덱을 전부 덱으로 되돌리고 셔플**할 수 있다.
  - 단, 이는 **완전히 턴을 포기하는 행위**다 → 적은 **그 턴에 예정되어 있던 행동(공격 등)을 수행**한다.
  - **설계 의도**: 극단적으로 **덱을 압축해 플레이하는 상황을 견제**하기 위한 장치(덱을 너무 작게 만들면 리셔플에 턴을 소모하고 그동안 적의 공격을 허용하게 됨).

### 2-3. 전투 보드 레이아웃
| 위치 | 요소 |
|------|------|
| 중앙 | 덱 |
| 상단 | **상단 핸드 (Upper Hand)** — 슬롯 5장, 무게 제한 21 |
| 하단 | **하단 핸드 (Lower Hand)** — 슬롯 5장, 무게 제한 21 |
| 좌측 | **에이스(강화 카드)** 영역 |
| 우하단 | **홀 카드 슬롯** |
| 좌상단 | **플레이어 체력** |
| 상단 중앙 | **적 스프라이트 + 적 체력 + 이번 턴 공격 예고** |

### 2-4. 턴 진행
- 한 전투는 **여러 턴**으로 진행된다(운이 좋으면 한 턴에 끝날 수도 있다).
- 한 턴 내 절차:
  1. 덱에서 **무작위로 카드를 한 장씩** 뽑는다.
  2. 플레이어가 그 카드를 **상단 핸드 / 하단 핸드 중 어디에 히트(hit)할지 결정**한다. → 이 고민·선택이 핵심 재미.
  3. 원하는 만큼 반복.
  4. 플레이어가 **스탠드(Stand)** 로 턴을 확정한다. — **스탠드는 오로지 플레이어의 결정이며 전용 버튼이 필요**하다.
- **데미지는 스탠드 시점에 계산**한다(2-5).
- 턴 종료 시 양 핸드의 카드는 **버린 카드 덱**으로 간다.

### 2-5. 데미지 계산 (스탠드 시점)
- **공격력 = (상단 핸드 가치 총합) × (하단 핸드 가치 총합)**
- **버스트 (핸드 무게가 제한 초과)**: **무게를 넘어선 그 핸드만** 5장 슬롯 중 **중앙(5칸 중 3번째) 슬롯을 제외한 모든 슬롯이 무효**가 되어, 해당 핸드는 **중앙 카드의 가치만** 계산에 들어간다. (버스트되지 않은 다른 핸드는 영향 없음. 무효 슬롯은 턴 종료까지 복구되지 않음.)
- **황금 코인** (배수 자원):
  - 핸드 무게가 무게 제한(기본 21)에 **정확히 일치** → 1개
  - 핸드의 **5장 슬롯을 가득** 채움 → 1개
  - **에이스 카드** 또는 **카드에 그려진 그림(효과) 조건 충족** 시 **추가 획득** (의도된 확장 — 코인 수 상한 없음)
- **최종 데미지 = 공격력 × 1.5^(황금 코인 수)**. 코인 1개당 기본 ×1.5(소수점은 **최종 계산에서 버림**, 플레이로 강화 가능). 예) 코인 4개 → 1.5⁴.

### 2-6. 적과 턴
- 플레이어의 (최종) 공격이 **적의 최대 체력을 넘기면** 적의 공격은 수행되지 않는다(= 처치).
- 적이 **생존**하면 적이 플레이어를 공격하여 체력을 깎는다. (또한 2-2의 '미사용 상태 덱 보충' 시에도 적의 행동을 허용한다.)
- 적은 다양한 공격을 하며, **이 아이디어는 점차 발전시켜 나간다.**

### 2-7. 승/패 조건
- 전투 승리: 적 체력 0 이하.
- **게임 승리: 보스 전투 8회(8막)를 모두 승리.**
- 패배: **플레이어 체력 0 → 런 종료.**

## 3. 게임 플로우 (진행 순서)

```
시작 덱 선택
   ↓
┌──── 한 막(Act) ───────────────────────────────────────────┐
│ [ 적 선택 ] → [ 여정 ] → [ 적 선택 ] → [ 여정 ] → [ 보스 전투 ] │
└──────────────────────────────────────────────────────────┘
   위 막을 총 8회 — 보스 8회를 모두 승리하면 게임 승리
```

- **적 선택**: 적의 종류와 **여정의 횟수**를 함께 제시한다.
  - 예) 고블린 - 여정 2회 / 멧돼지 - 여정 3회
  - 기본은 **2지선다**, 조건을 통해 선택지를 늘릴 수 있다(선택지 수를 **가변적으로** 표시).
  - **어려운 적일수록 더 많은 수의 여정을 제공**한다(고난도 = 여정 多 = 보상 多).
- **여정 종류** (구상 단계 · 확장 가능):
  - 플레잉 카드 상인 / 홀 카드 상인 / 에이스 상인
  - **화가** — 이미 보유한 플레잉 카드에 그림을 그려줌(효과 부여)
  - 체력 회복 이벤트 / 금화 증가 이벤트
  - 카드 교환 / 희생을 감수하고 이득을 얻는 이벤트 등
- 강화 카드(에이스)는 **상점과 여정**을 통해 얻는다.

| 데미지 계산 | (상단 가치합 × 하단 가치합) × 1.5^코인, 핸드별 버스트 처리 |
| 황금 코인 | 정확히 21 / 5슬롯 / 에이스·그림 조건 → ×1.5 배수 |
| Run / 진행 | 8막 · 적 선택 · 여정 · 보스 |
| 여정/상점 | 상인(플레잉·홀·에이스)·화가·이벤트 등 |
